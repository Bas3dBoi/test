# **Project Goal**

Develop a user-friendly budgeting web application that helps users manage their finances through intuitive tools and visualizations.

# **Project Objectives**

- Enable secure user authentication and account management.
- Provide tools for creating and managing budgets with user-defined inputs.
- Generate visual reports (bar graphs, pie charts) to display spending and budgeting trends.

# **Project Scope**

The project will develop a website that focuses on providing a financial management application for a user to add expenses, track monthly payments, and set budgets. The application includes a budget calculator and visual reporting tools and will support USD currency only.

**Included**:

- Web application allowing user to upload financial details and output reports and visualizations
- Core features like user authentication, account management, and budgeting tools
- Visualizations for financial breakdowns using bar graphs and pie charts

**Excluded**:

- Advanced functionalities such as W-2 integration or subscription-based premium features (to be considered for future development)
- Anything pertaining to the formal deployment and real-world use of the application in a business setting (i.e. third-party service integration, AWS hosting, subscription payment processing, third-party database hosting, etc.)
- Any currency other than USD
